# 업무 집중 타이머 (FocusTimer)

항상 화면 맨 위(상단 중앙)에 떠 있으면서 **순 업무시간**을 측정하는 Windows용 작은 타이머입니다.

## 다운로드
- **[FocusTimer.exe 바로 받기](https://github.com/hojung1231/focus-timer/raw/main/download/FocusTimer.exe)**
- exe 다운로드가 막히면: **[FocusTimer.zip 받기](https://github.com/hojung1231/focus-timer/raw/main/download/FocusTimer.zip)** → 압축 풀고 실행

설치가 필요 없습니다. Windows 10/11에 기본 포함된 .NET Framework 4.8로 동작합니다.

> 처음 실행할 때 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명이 없는 프로그램이라 나오는 경고입니다.)
> 예전 버전이 켜져 있으면 먼저 닫아 주세요. (한 번에 하나만 실행됩니다.)

## 사용법
실행하면 **홈 화면**에서 버전을 고릅니다. 각 화면의 배너 `⌂` 버튼으로 언제든 홈으로 돌아갑니다.
홈에 갔다 와도 기록은 그대로 유지되고, 홈에 있는 동안에도 측정은 계속됩니다.

### VER 1 · 직접 기록
| 동작 | 결과 |
|---|---|
| 업무 입력 후 **Enter** | 시간 측정 시작 (초록색) |
| 업무 박스 클릭 (글자 바깥 부분) | 정지 ↔ 재시작 |
| 업무 박스의 **글자 부분** 클릭 | 텍스트 수정 (Enter 확정, Esc 취소) — 시간 상태는 그대로 |
| 배너의 `+ 새 업무` | 오른쪽에 새 업무 박스 추가 |
| 업무 박스 우클릭 | 텍스트 수정 / 시간 초기화 / 업무 삭제 |
| 배너 `↺` | 모든 업무 시간만 0으로 / 업무 모두 지우기 |

- 한 번에 하나의 업무만 측정됩니다. 다른 업무를 시작하면 진행 중이던 업무는 자동으로 정지됩니다.
- 30초 동안 키보드·마우스 입력이 없으면 자동으로 멈추고(`자리 비움`), 다시 움직이면 자동으로 이어서 잽니다. 움직임이 없던 30초는 빼고 계산합니다.
- 기록은 `%APPDATA%\FocusTimer\tasks.txt`에 저장되고, 다시 실행하면 정지 상태로 복원됩니다.

### VER 2 · 자동 감지
지금 사용 중인 창(프로그램 + 창 제목)을 1초마다 확인해서 작업 이름을 자동으로 붙이고 시간을 잽니다.
예: `2분기 실적 보고서.docx - Word` → **Word / 2분기 실적 보고서.docx**

| 화면 | 의미 |
|---|---|
| 초록 박스 | 지금 하고 있는 작업 |
| 주황 박스 + 빨간 줄 `↩ 돌아가기` | 딴짓 중 — 누르면 하던 작업 창이 바로 앞으로 옴 |
| 회색 박스 | 다른 작업 — 누르면 그 창으로 이동 |
| 박스 순서 | **오래 한 작업일수록 왼쪽** (기본 3개, 옵션에서 1~5개, 지금 하던 작업은 항상 표시) |
| 아래 줄 `● 순 업무` | 딴짓·자리 비움을 뺀 순수 업무 시간 합계 |

- **딴짓 기준**: 카카오톡 등 프로그램 전체, 또는 웹브라우저 제목에 YouTube·넷플릭스·인스타그램·웹툰 등이 있는 경우.
  `%APPDATA%\FocusTimer\distractions.txt`를 메모장으로 고치면 바로 반영됩니다. (우클릭 → `딴짓 규칙 편집…`)
- 배너 `↺` → 자동 감지 기록(작업 목록과 시간) 모두 지우기
- 작업 박스 우클릭 → `이 프로그램을 딴짓으로 분류` / 빨간 줄 우클릭 → `이건 업무예요`
- 30초 동안 키보드·마우스 입력이 없으면 **자리 비움**으로 보고 시간을 세지 않습니다. (그 30초도 빼고 계산)
- 창 정보는 이 PC 안에서만 쓰이고 어디에도 전송되지 않습니다.
- 웹브라우저는 창 단위로 돌아갑니다. 돌아간 창에서 다른 탭을 보고 있었다면 그 탭이 보입니다.

### 공통
- 항상 다른 창 위에, 모니터 상단 중앙에 뜹니다. 배너를 끌어서 옮기고, 더블클릭하면 상단 중앙으로 돌아옵니다.
- **옵션 (배너의 ⚙ 또는 배너 우클릭)**
  - 투명도: 0~70% (기본 30%)
  - 표시할 작업 수: 자동 감지에서 많이 한 순서대로 1~5개 (기본 3개)
  - 마우스를 올리면 선명하게 (기본 켜짐)
  - 설정은 `%APPDATA%\FocusTimer\settings.txt`에 저장됩니다.
- **업데이트**: `⚙` 메뉴에 있습니다. 새 버전이 나오면 `⚙` 버튼이 **파랗게** 바뀌고, 메뉴 맨 위의 `⬆ 새 버전 … 업데이트`를 누르면 자동으로 바꾸고 다시 시작합니다. (VER 1 기록은 유지)
  새 버전이 없을 때는 `⚙` → `업데이트 확인`으로 바로 확인할 수 있습니다.

## 빌드
.NET SDK 8 이상이 있으면 Windows/Linux/macOS 어디서든 빌드할 수 있습니다.

```bash
dotnet build -c Release
```

결과물: `bin/Release/net48/FocusTimer.exe`

## 새 버전 배포
1. `FocusTimer.csproj`의 `<Version>`을 올립니다. (예: 2.1.0 → 2.2.0)
2. `./release.sh "바뀐 점 1" "바뀐 점 2"` 실행 → `download/`에 exe, zip, `version.txt`(버전·SHA-256·변경 내용)가 만들어집니다.
3. 커밋하고 `main`에 올리면, 실행 중인 프로그램들이 3시간 안에(또는 배너 우클릭 → 업데이트 확인) 업데이트 버튼을 띄웁니다.
