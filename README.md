# 업무 집중 타이머 (FocusTimer)

항상 화면 맨 위(상단 중앙)에 떠 있으면서 **순 업무시간**을 측정하는 Windows용 작은 타이머입니다.

## 다운로드
[Releases](../../releases) 페이지에서 `FocusTimer.exe`(또는 `FocusTimer.zip`)를 받아 실행하세요.
설치가 필요 없습니다. Windows 10/11에 기본 포함된 .NET Framework 4.8로 동작합니다.

> 처음 실행할 때 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명이 없는 프로그램이라 나오는 경고입니다.)

## 사용법
실행하면 **홈 화면**에서 버전을 고릅니다. 각 화면의 배너 `⌂` 버튼으로 언제든 홈으로 돌아갑니다.

### VER 1 · 직접 기록
| 동작 | 결과 |
|---|---|
| 업무 입력 후 **Enter** | 시간 측정 시작 (초록색) |
| 업무 박스 클릭 (글자 바깥 부분) | 정지 ↔ 재시작 |
| 업무 박스의 **글자 부분** 클릭 | 텍스트 수정 (Enter 확정, Esc 취소) — 시간 상태는 그대로 |
| 배너의 `+ 새 업무` | 오른쪽에 새 업무 박스 추가 |
| 업무 박스 우클릭 | 텍스트 수정 / 시간 초기화 / 업무 삭제 |

- 한 번에 하나의 업무만 측정됩니다. 다른 업무를 시작하면 진행 중이던 업무는 자동으로 정지됩니다.
- 기록은 `%APPDATA%\FocusTimer\tasks.txt`에 저장되고, 다시 실행하면 정지 상태로 복원됩니다.

### VER 2 · 자동 감지
지금 사용 중인 창(프로그램 + 창 제목)을 1초마다 확인해서 작업 이름을 자동으로 붙이고 시간을 잽니다.
예: `2분기 실적 보고서.docx - Word` → **Word / 2분기 실적 보고서.docx**

| 화면 | 의미 |
|---|---|
| 초록 박스 | 지금 하고 있는 작업 (최근 작업 최대 3개 표시) |
| 주황 박스 + 빨간 줄 `↩ 돌아가기` | 딴짓 중 — 누르면 하던 작업 창이 바로 앞으로 옴 |
| 회색 박스 | 최근에 했던 다른 작업 — 누르면 그 창으로 이동 |
| 아래 줄 `● 순 업무` | 딴짓·자리 비움을 뺀 순수 업무 시간 합계 |

- **딴짓 기준**: 카카오톡 등 프로그램 전체, 또는 웹브라우저 제목에 YouTube·넷플릭스·인스타그램·웹툰 등이 있는 경우.
  `%APPDATA%\FocusTimer\distractions.txt`를 메모장으로 고치면 바로 반영됩니다. (우클릭 → `딴짓 규칙 편집…`)
- 작업 박스 우클릭 → `이 프로그램을 딴짓으로 분류` / 빨간 줄 우클릭 → `이건 업무예요`
- 5분 동안 키보드·마우스 입력이 없으면 **자리 비움**으로 보고 시간을 세지 않습니다.
- 창 정보는 이 PC 안에서만 쓰이고 어디에도 전송되지 않습니다.
- 웹브라우저는 창 단위로 돌아갑니다. 돌아간 창에서 다른 탭을 보고 있었다면 그 탭이 보입니다.

### 공통
- 항상 다른 창 위에, 모니터 상단 중앙에 뜹니다. 배너를 끌어서 옮기고, 더블클릭하면 상단 중앙으로 돌아옵니다.

## 빌드
.NET SDK 8 이상이 있으면 Windows/Linux/macOS 어디서든 빌드할 수 있습니다.

```bash
dotnet build -c Release
```

결과물: `bin/Release/net48/FocusTimer.exe`
